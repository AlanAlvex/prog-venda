# Sistema de Vendas

Sistema web desenvolvido em Delphi utilizando UniGUI
e Firebird.

## Arquitetura

- MVC
- DAO
- Model
- Controller

## Tecnologias

- Delphi
- UniGUI
- Firebird
- SQL

## Funcionalidades

- Cadastro de produtos
- Cadastro de clientes
- Vendas
- Consulta de dados
- Persistência em Firebird
